# 三键导航与只读诊断技术路线

## 基线与交付边界

- 基线：`efc226e`，功能分支：`feature/oled-buttons-diagnostics`。仅修改固件仓库。
- 三键只控制 OLED 页面，不改变空调影子状态、不写配置/状态 NVS、不发红外、不发布控制消息。服务端、MQTT 契约和失联保护策略不变。
- 初始阶段（2026-10-27）没有按键模块，只做主机测试与 `esp32dev/selftest` 编译。2026-10-31 用户确认按接线文档完成接线并可控制测试，进入串口、烧录与硬件联调阶段；待硬件验收完成后另行授权合并。

## 硬件与交互

- 三个常开、松手复位机械按键：LEFT / OK / RIGHT；GPIO25 / 26 / 27，各接 GPIO 与 GND，内部上拉、低电平有效。购买和接线前核实实际板型、引出和占用；不复用 BOOT(GPIO0)。未接模块时维持自动轮播。
- 非阻塞逐循环采样；软件去抖 30ms，OK 稳定按下 800ms 触发一次长按，释放不再短按；左右长持不连发。上电或初始化时按住须先释放再重新按下才生效。
- 左右短按：循环切换四个概览页并固定。OK 短按：自动/固定切换，恢复自动时重新计满 5 秒。
- OK 长按：进入/退出五类诊断；详情中左右循环切项，详情不轮播；OK 短按不退出详情、不改变返回时的概览模式。退出回到原概览页与原模式，重新开始轮播计时。
- 固定仅停止切页，数据继续刷新；显示 AUTO / HOLD / DIAG。不引入双击、组合快捷操作、关机、重启、清配置或其他可写诊断。
- 正常运行阶段才启用三键；配网/启动/自检的 `display_lines()` 手动画面独占屏幕，导航不可抢占，交还时恢复正常渲染。BOOT 清配置功能保持原样。

## 模块职责与接口

1. `ui_navigation.h/.cpp`：平台无关的按键去抖/短长按事件和导航状态；只用显式 `uint32_t now_ms` 及无符号差值处理回绕。
2. `buttons.h/.cpp`：唯一 GPIO 适配层，初始化 INPUT_PULLUP、采样并把事件交给显示导航接口；不依赖空调控制模块。
3. `display.h/.cpp`：维护导航、动画和只读快照，保留四页概览与保护优先徽标；按键打断动画并立即标脏，自动切页仍保持约 240ms 动画和独立裁剪。
4. `net_mqtt.h/.cpp`：增加心跳 seen/last_received_ms 只读快照；不修改到达时间判活公式和超时。
5. `main.cpp`：记录 DHT 最近尝试/最近成功的 seen/时间，构建显示快照，setup 完成后初始化按键，loop 非阻塞扫描。保护与命令执行顺序不变。

## 诊断数据

| 项目 | 字段及未知语义 |
|---|---|
| NETWORK | Wi-Fi / MQTT 连接、IP；不展示 SSID 密码、broker 凭据 |
| HEARTBEAT | 是否收到过、现有判活结果、最近到达距今；未收到显示 NOT RECEIVED |
| SENSOR | 未尝试显示 NOT READ；最近尝试成功/失败、距今、最近成功距今；失败不显示旧温湿度为有效值 |
| FAILSAFE | 未武装/武装/已触发、健康联系状态、距最后健康联系；未武装显示 NO CONTACT；不重算或修改保护决策 |
| BOOT/FW | RTC 启动次数、复位原因、版本哈希、构建日期时间；启动计数不是全生命周期累计次数 |

计时字段由当前快照时刻与真实时间戳相减；未知由显式 seen 标记表达，不把 0 当作未知，也不拿 0 秒冒充正常。毫秒差可处理一次计数回绕；不声称支持超过约 49.7 天未刷新的年龄。屏幕为现有 ASCII 字体，中文语义使用短英文显示。
