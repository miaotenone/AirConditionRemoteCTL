# 串口协议说明（高配版红外模块）

通用帧格式：

| 字段 | 字节数 | 说明 |
|---|---|---|
| 帧头 | 1 | 固定 `0x68` |
| 长度 | 2 | 整帧字节数，低字节在前 |
| 模块地址 | 1 | 默认 `0xFF`（广播） |
| 功能码 AFN | 1 | 见下 |
| 数据 | N | 依功能码而定 |
| 校验和 | 1 | 依功能码而定 |
| 帧尾 | 1 | 固定 `0x16` |

串口：**115200 bps，8 数据位，1 停止位，无校验**（485 版为 9600）。

## 功能码

| AFN | 名称 | 长度 |
|---|---|---|
| `0x30` | 空调控制（多参数） | `0x0C` |
| `0x31` | 空调控制（单参数） | `0x09` |
| `0x10` | 进入内部存储学习模式 | `0x08` |
| `0x12` | 发送内部存储指令 | `0x08` |

## 0x30 多参数控制（本固件使用）

```
[0]68 [1]0C [2]00 [3]FF [4]30 [5]品牌 [6]开关 [7]模式 [8]温度 [9]风量 [10]55 [11]16
```

- 校验和固定 `0x55`。
- 开关：开 `0x01` / 关 `0x00`
- 模式：自动 `0x00` / 制冷 `0x01` / 除湿 `0x02` / 送风 `0x03` / 制热 `0x04`
- 温度：16~30℃ 直接作为字节，即 `0x10`~`0x1E`（24℃ = `0x18`）
- 风量：自动 `0x00` / 低速 `0x01` / 中速 `0x02` / 高速 `0x03`

示例（美的1，开，制冷，24℃，自动风）：

```
68 0C 00 FF 30 10 01 01 18 00 55 16
```

## 0x31 单参数控制

```
[0]68 [1]09 [2]00 [3]FF [4]31 [5]索引 [6]数据 [7]55 [8]16
```

索引：品牌 `0x00` / 开关 `0x01` / 模式 `0x02` / 温度 `0x03` / 风量 `0x04`；数据取值同上。

## 0x10 / 0x12 学习与回放

```
学习第 N 路： 68 08 00 FF 10 (N-1) 校验 16
发送第 N 路： 68 08 00 FF 12 (N-1) 校验 16
```

校验和 = 从「模块地址」(`0xFF`) 起到数据末尾逐字节累加取低 8 位。例如学习第 1 路：
`0xFF + 0x10 + 0x00 = 0x010F` → `0x0F`，即 `68 08 00 FF 10 00 0F 16`。
